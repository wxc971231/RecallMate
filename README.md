# RecallMate

离线填空背诵工具，Windows x64 文件夹便携版，版本 0.1.4。

## 直接体验

构建后的文件位于 `release/`：

- `RecallMate-0.1.4-Portable/RecallMate.exe`：双击启动，保留整个文件夹。
- `RecallMate-0.1.4-Portable.zip`：干净的发布压缩包，解压后使用，不含个人题库。
- `SHA256SUMS.txt`：当前发布 ZIP 的 SHA-256 校验值。

今后只分发文件夹便携版，不生成安装版或自解压 EXE。`release/` 只保留当前版本的上述三个发布项；构建中间产物放在 `.cache/build/`。重新发布前，旧发布目录中的 `data` 会先完整备份到 `.cache/release-data-backups/`，发布文件夹与 ZIP 都保持干净。请将实际使用的软件复制到独立位置，避免把 `release/` 当作日常题库存储目录。

无需安装 Node.js，无需启动服务器，运行时不需要网络。首版尚未进行发布者代码签名。

打开应用后，点击“体验示例题库”，确认导入 20 道综合知识题，即可开始练习。也可以导入 `examples/综合知识示例.md` 或自己的题库。示例题由常见知识点组成，未声称来源于真实考试。

## 已实现

- 简洁界面：顶部导航、题库表格、题目分页列表；练习页只保留题目、进度与底部操作，去除口号、插画、头像与统计卡片。
- 顶部“字号”：界面字号 12–20px、练习字号 18–40px 分别调整，支持滑块、加减和恢复默认；默认分别为 14px、24px。题目、输入框和提示字符同步缩放，自动保存，重开仍生效。
- UTF-8 Markdown/TXT 导入、粘贴导入、错误行号、导入前预览。
- 题库搜索、重命名、删除；题目搜索、新增、编辑、删除。
- 顺序、随机、单题、从指定题开始、错题本、本轮错题重练。
- 内嵌填空、多个合法答案、自动聚焦、Enter 判题、完成后再次 Enter 切题。
- 答案按住显示，松开/移出/失焦还原；逐 Unicode 字符提示；放弃补全并标记系统字符；直接跳过。
- 错题计数、求助计数、独立完成统计；移出错题本保留历史；本轮总结。
- 自动保存、恢复练习、串行原子写入、上一份有效备份、JSON 导入导出。

## 题库格式

```md
# 生物学复习

光合作用的能量来源是{{光能}}，主要发生在{{叶绿体}}中。

---

水的化学式为{{H₂O|H2O}}。
```

只在独占一行的 `---` 处分题，普通换行和空行均属于当前题目。第一项是标准答案，`|` 分隔其他可接受答案。答案只去除首尾空白，其他大小写、标点、全半角均严格匹配。不支持答案内的 `|` 或花括号转义，也不解析复杂 Markdown 排版。

## 练习规则

输入框内不显示数字占位符。按 Enter 后，正确字符用绿色显示，不匹配字符用红色显示；漏字时保留后面的正确字符并提示尚未完整，不直接泄露缺失答案。修改输入后清除该空的旧判定，下一次 Enter 再判断。部分正确和仅缺内容的提交均沿用原错题统计，同一次作答最多记一次。

顿号、“和”及两者混合连接的并列内容都支持换序：

- 单个空：`{{甲和乙}}` 可输入 `乙和甲`；`{{a、b、c 和 d}}` 可输入 `d 和 c、a、b`，按项目数量及内容匹配；每个项目的首尾空白会被去除。
- 多个空：`{{甲}} 和 {{乙}}` 或 `{{a}}、{{b}}、{{c}} 和 {{d}}` 可交换各空答案，按整个连续组一对一匹配。重复项不抢占已判对的选项；重叠合法答案会重新分配，避免按位置或贪心匹配产生假错误。

只有分隔文本为顿号或“和”（可带空白）的相邻空才组成组；混合连接也会合为一组，逗号、分号以及其他解释文字不会自动合并。单个空内保留“和平”“共和国”“温和”等常见词中的“和”；遇到有歧义的并列表达，可在连接词“和”两侧添加空格明确分项。此规则按题库语法识别，不推断题意；有先后次序的题目应避免使用这种无序组写法。`|` 仍表示多个完整的合法答案，不会将不同备选列表的项目混合使用。少项、多项、重复项及空项目不能完整通过。

提示沿用当前匹配的目标，保留正确片段、移除不匹配内容，每次最多补入一个 Unicode 字符；合法的换序或备选答案不会被提示改回固定顺序。放弃时保留已经正确的内容，系统替换或补入的字符仍用黄色标记。字符反馈与用户/提示/放弃的来源标记独立维护。

Enter 提交当前空，并聚焦第一个未答对的空。全部正确后保留反馈，再按 Enter 进入下一题。中文输入法组合期间的回车不会提交，长按回车的重复事件会被忽略。每项操作也有可点击按钮。

提示补满后仍需 Enter 判定；后续提示跳到下一个尚未补满的空。修改正确答案会撤回完成状态，同一 Attempt 的统计会基于作答前快照重新投影，因此不会重复累计。查看答案只改变显示，不覆盖原输入、判题状态和字符来源。

一次作答内不论答错多少次、求助多少次，错次和求助次数分别最多增加 1。纯跳过不进入错题本。曾经答错或求助后再完成，不算独立完成。

编辑题目会清除当前题库的整轮练习进度，界面已明确提示；只改题干时保留历史统计，改变答案时需确认重置该题统计。删除当前题目时清除当前练习，删除其他题目则修正队列和总结引用。

## 数据与备份

所有打包版本都以 EXE 所在文件夹为根目录，应用管理的可写数据统一放在旁边的 `data/`。通过“设置 → 打开数据目录”查看实际路径：

```text
RecallMate-0.1.4-Portable/
  RecallMate.exe
  resources/                 # 应用与示例题库
  ...                        # Electron 所需的 DLL、资源与许可证，请保留
  使用说明.txt
  data/
    banks/<bank-id>.json      # 题库、错题统计与当前进度
    backups/<bank-id>.json.bak
    runtime/                 # Chromium 配置、网络状态、GPU 与代码缓存
    temp/                    # 临时文件
    logs/                    # 日志
    crashes/                 # 崩溃转储
    exports/                 # 手动导出的 JSON 备份
    app-settings.json        # 界面字号与练习字号，含版本号
    app-settings.json.bak    # 上一份有效的字号设置
```

每份 JSON 是 `{ schemaVersion: 1, bank, session? }`，题库、统计和当前进度处于同一个文件内，避免跨文件保存一半的情况。输入停止 400ms 后保存；判题、提示、切题和管理操作立即保存；关闭窗口会等待保存完成。页面右上角会显示保存状态，保存失败时保留窗口、重试保存。

文件写入按队列串行执行，先保留有效旧文件，再写同目录临时文件并替换。读取主文件失败时尝试 `.bak`；后续写入会把损坏原件保留为 `.corrupt-时间戳`。主文件和备份均损坏时保留原件并禁止覆盖，提示用户手动修复或从导出备份恢复为新题库。

在题库详情点“导出备份”，会把包含题库、统计与当前进度的 JSON 写入 `data/exports/`，文件名包含时间和随机标识，重复导出不会覆盖已有文件，也不会弹出选择外部保存位置的对话框。通过“导入新题库 → 选择本地文件”选择 JSON 恢复，同 ID 的题库必须确认覆盖。导入可读取其他位置的文件，软件不会改写源文件，并要求系统不将选择的文件加入最近文件列表。应用只接受受支持版本、有效 UUID 和引用完整的备份。

便携版不自解压，不在系统 TEMP 展开运行时。关闭后复制整个文件夹，就能把软件、题库和进度一起搬走；不要只复制 EXE，也不要删除 `data`。相对位置随文件夹自动变化，不保存机器相关的固定数据路径。文件夹不可写时显示错误并退出，不会回退到 AppData。打包版本忽略外部 `RECALLMATE_DATA_DIR` 覆盖，开发/测试版才接受该环境变量。

在 Electron ready 之前同步重定向 `appData`、`userData`、`sessionData`、临时目录、日志与崩溃目录，并为子进程设置 TEMP/TMP/TMPDIR。开发版默认写入项目 `.cache/development-data/`。路径约束覆盖软件与内置 Chromium 可配置的文件写入；Windows 自身的 Prefetch、事件记录、文件对话框记录、驱动及杀毒软件的记录不由应用管理，因此不承诺系统级“零痕迹”。[Electron 路径说明](https://www.electronjs.org/docs/latest/api/app#appgetpathname)

0.1.0 的 `%APPDATA%/RecallMate/` 数据不会被新版自动读取或删除。迁移时先关闭旧版，再把旧目录里的 `banks`、`backups` 复制到便携版的 `data`。本机可使用以下只复制、不删除源文件、不覆盖已有不同文件的迁移工具：

```powershell
node scripts/migrate-local-data.cjs "$env:APPDATA/RecallMate" "release/RecallMate-0.1.4-Portable"
```

发布脚本先在 `.cache/` 准备完整的干净文件夹与 ZIP，再备份旧发布目录内的数据并清理旧发布项，最后发布当前版本。不会将个人题库打进发布包。发现未知文件、链接目录或正在从 `release/` 运行的应用时会停止，避免误删或替换使用中的文件。浏览器预览独立使用浏览器本地存储，与桌面版相互隔离，不属于此文件夹便携模式。

从 0.1.1 等旧便携版升级时，请先关闭旧版，把旧软件的 `data` 作为迁移来源，例如：

```powershell
node scripts/migrate-local-data.cjs "C:/Users/PC/Desktop/RecallMate-0.1.1-Portable/data" "release/RecallMate-0.1.4-Portable"
```

迁移工具只复制题库、自动备份及已有的字号设置；保留原文件，不覆盖新版中内容不同的文件。不要以发布 ZIP 替换自己的整个 `data`。

## 开发与构建

已验证的本机环境：Node.js 24.11.1、npm 11.6.2、Git 2.51.0.windows.2。依赖的实际版本锁定于 `package-lock.json`。使用 React 19、TypeScript 5.9、Vite 7、electron-vite 4、Electron 45.2.1、electron-builder 26、Vitest 3。

如果 Node.js 未加入 PATH，可使用本机已存在的 Trae 运行时：

```powershell
$env:Path = 'C:\Users\PC\.trae\binaries\node\versions\24.11.1;' + $env:Path
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
npm.cmd ci
npm.cmd run dev
```

也可以在 VS Code 执行任务“RecallMate: 启动桌面开发版”，或运行 `powershell -File scripts/dev.ps1`。脚本会先使用 PATH 中的 Node.js，再查找这台电脑的 Trae 目录，不会永久更改环境变量。

Electron 45 需要显式安装二进制，本项目通过 `postinstall: install-electron` 自动处理。首次安装和打包需要联网下载 npm 依赖、Electron 与打包组件。

```powershell
npm.cmd test             # 领域逻辑与文件存储测试
npm.cmd run typecheck    # TypeScript 检查
npm.cmd run build        # 生产构建
npm.cmd run test:desktop # 实际 Electron 界面 / IPC / 保存恢复测试
npm.cmd run dist         # Windows x64 文件夹便携版与干净 ZIP
```

桌面测试以隐藏的离屏窗口运行，使用 `artifacts/desktop-test-时间戳/` 独立数据目录，不触碰个人题库，截图和结果保存在 `artifacts/`。正式应用使用正常窗口。生产版通过 `loadFile` 加载打包资源，不启动 HTTP 服务。

## 验证与限制

核心测试覆盖解析错误、多答案、严格匹配、Unicode、字符来源、重复结算、完成后修改、跳过规则、20 题完整流程、恢复、并发写入、备份与损坏保护。桌面测试覆盖真实 sandbox/preload/IPC、导入、自动聚焦、判题、模拟 IME 事件、按住答案、提示、放弃、持久化、页面重载和最小窗口布局。

0.1.2 新增字号范围校验、快速调节的串行保存、异常设置恢复；桌面检查包含字号实时应用、题目与输入框同步缩放、字号持久化、恢复默认、分页、最大字号下最小窗口的布局和操作可见性，以及调节字号前后作答状态不变。

真实微软拼音/搜狗输入法的选词时序、触屏手势以及不同 DPI 仍建议人工体验验证；当前自动测试使用合成的组合输入事件。尚未实现 Android、云同步、OCR、AI 判题或自动更新，这些也不属于本次首版范围。
