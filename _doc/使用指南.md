# RecallMate 使用指南

[返回 README](../README.md) · [开发与发布](开发与发布.md) · [Android 开发](RecallMate_Android.md)

## 导入与管理题库

支持 UTF-8 编码的 Markdown、TXT，以及 RecallMate 导出的 JSON。可选择文件或粘贴文本；导入前会显示题目预览和格式错误位置。内置 20 道综合知识示例题用于体验，未声明来源于真实考试。

题库支持搜索、重命名和删除；题目支持分页、搜索、新增、编辑与删除。练习可选择顺序、随机、单题、从指定题开始、错题本，以及重练本轮错题。

## Windows 多题型练习（0.2.0）

判断、单选、多选与填空可放在同一个题库中，使用 [.questionbank.json 内容包](题库内容包格式.md) 导入。示例见 [四题型示例](../examples/四题型示例.questionbank.json)。Android 0.2.0 与 Windows 0.2.x 共用四题型功能。

判断题需主动选择“正确”或“错误”；单选选择一项，多选可勾选多项。空提交只提醒选择，不记错。提交后锁定本次选择，显示标准答案和结果；多选按精确集合判定，分别标记漏选与错选。解析和相关知识点只在提交或查看答案后展示，阅读答后内容不增加求助次数。

“不会／看答案”会结束本题并记一次求助，保留原选择；“跳过”不加入错题本。Enter 提交，再次按下进入下一题；Shift + F3 查看答案，F4 跳过。F1／F2 仅用于填空。未提交的选择和提交后的锁定结果都可以退出后继续。

题库详情和错题本可按题型筛选；选择“开始练习”会使用筛选后的题目，继续练习则恢复原固定队列。每个题库保留自己的错题记录，全局错题页只做汇总。

导入内容包可选择新建或追加。重复 ID 同内容跳过，异文冲突整批停止；追加不会把新题塞入当前练习。可以手动新增或编辑四种题型；修改题干、选项或答案前会确认重置本题统计，解析和关联知识点的调整保留当前进度。

“导出题库内容”用于分享、追加，不含学习记录；“导出备份”包含题目、统计及当前进度，用于完整恢复。旧 V1 数据首次保存前，会在各自数据目录的 migrations 中保留原始字节。新版 V2 备份不能导入旧版应用或 Android 0.1.2；回退时使用升级前 data 或迁移原件。

### 判断原因与简洁练习界面

Windows 0.2.8 的四种题型共用一条紧凑工具栏，仅保留退出、题号／总题数、字号与设置，题库名可悬停查看。去掉重复标题、进度条、未作答时的常驻提交提示以及空下方的重复正确标签；题目区域独立滚动，底部操作按钮保持可见。

判断题的“正确／错误”并排显示。内容包提供 `explanation` 后，答后按“解析 → 相关知识点”上下排列，两块分别点击展开或收起，默认均展开。解析先引用知识点编号及关键原文，再说明题干正误或选项取舍的核心判据。选择题保持选项逐行显示，判断题的两个选项并排显示。知识点标题仅显示一个编号，来源与编号同一行显示。知识点正文使用紧凑行距，编号列表前的多余空行按单次换行显示，原文件及普通段落分隔不变。解析是题库内容，不由应用自动生成，新增或编辑题目时可以填写。没有解析的旧题仍保留知识点展示。Windows 新题初次打开时不自动聚焦答案，点击或按 Tab 后仍可正常输入、选择；填空提交后继续定位到下一空。

### 逐选项解析

选择题可按 A、B、C 等逐项解释，每项依次写应选／不选结论、知识点原文和对应分析。显示时会根据 A、B 等字母补上题目中对应选项的完整内容，不必在解析字段中重复抄写选项。以 `- ` 开头分项，续行填写正文，显示时自动排成无序列表；知识点引用单独缩进。题库仍使用原来的 explanation 字符串，无需增加字段。

```text
- A：不选
  知识点 25：“解密时间已到或者符合解密条件的，自行解密”
  该选项符合自行解密条件；本题找错误项，因此不选。

- B：应选
  知识点 25：“应当在原保密期限届满前重新确定密级、保密期限和知悉范围”
  选项写成届满后，时点错误，因此应选。
```

上述片段只说明解析的写法，正式内容包的题干、选项和标准答案仍需完整填写。

## 编写题目

```md
# 生物学复习

光合作用的能量来源是{{光能}}，主要发生在{{叶绿体}}中。

---

水的化学式为{{H₂O|H2O}}。
```

- `{{答案}}` 表示填空；`|` 分隔其他合法答案，第一项是标准答案。
- 只有独占一行的 `---` 会分题，普通换行和空行仍属于当前题目。
- 答案会去除首尾空白，其余大小写、标点和全半角严格匹配。
- 不支持答案中的 `|` 或花括号转义，也不解析复杂 Markdown 排版。

### 并列答案换序

Windows 0.1.6 起、Android 0.2.0 起默认开启 **填空严格模式**，按文档固定顺序判题；单个空内的并列项目和多个空之间都不可交换，提示、按住答案与放弃也按原文位置处理。文档通过 `|` 明确列出的备选答案仍然有效。

在“设置 → 答题规则”中关闭严格模式后，适用以下换序规则。开关自动保存，从下一题或新练习起生效；当前题和旧版未完成题沿用开始时的规则，已有统计不会被追溯修改。

| 写法 | 可接受的换序示例 |
| --- | --- |
| 一个空：`{{甲和乙}}` | `乙和甲` |
| 一个空：`{{a、b、c 和 d}}` | `d 和 c、a、b` |
| 多个空：`{{甲}} 和 {{乙}}` | 第一个填乙，第二个填甲 |
| 多个空：`{{a}}、{{b}}、{{c}} 和 {{d}}` | 四个空之间任意交换 |

顿号、“和”及混合连接都支持换序，每项只能使用一次。少项、多项、重复项及空项目不能完整通过。多个空按整个连续组一对一匹配，重叠合法答案会重新分配，重复项不会抢占已判对的选项。

相邻空之间只有顿号或“和”（可带空白）时才组成组，逗号、分号和其他解释文字不会自动合并。单个空内会保留“和平”“共和国”“温和”等常见词中的“和”；有歧义时，可在连接词“和”两侧添加空格明确分项。

规则按题库语法识别，不推断题意。有先后次序的内容应避免写成无序组。`|` 表示多个完整合法答案，不会把不同备选列表中的项目混用。

## 作答、提示与判题

Windows 默认 Enter 提交当前空，并聚焦第一个未答对的空；本题全部正确后保留反馈，再按一次进入下一题。Android 点击“确认答案”和“下一题”。Windows 的按键可在设置中修改或停用。

正确字符显示绿色，不匹配字符显示红色。漏字时保留已输入的正确片段并提示尚未完整，不直接泄露缺失答案。修改输入后清除该空的旧判定，下次提交再判断。

| 操作 | 规则 |
| --- | --- |
| 按住查看答案 | 仅临时改变显示，不覆盖输入、判题状态或字符来源；松开、移出或失焦后还原 |
| 提示 | 保留正确片段、移除不匹配内容，每次最多补入一个 Unicode 字符 |
| 放弃 | 保留正确内容并补全本题，系统替换或补入的字符显示黄色 |
| 跳过 | 直接切题，纯跳过不加入错题本 |

提示沿用当前匹配目标，不会把合法换序或备选答案强行改回固定顺序。提示补满后仍需提交判定；继续提示会选择下一个尚未补满的空。

中文输入法选词期间的 Enter 不会提交。Windows 快捷键在弹窗、字号调整期间暂停，长按产生的重复事件会被忽略。查看答案期间不接受答案编辑。

Android 键盘弹出时会收起标题、退出导航、进度条和版本状态栏，保留题号、填空与操作按钮；题目可独立上下滚动。关闭键盘恢复完整导航，点击提示与按住答案不会主动收起键盘。

## 统计与进度

同一次作答内，无论答错或求助多少次，错次和求助次数分别最多增加一次。部分正确、仅缺内容的提交也计一次错题；曾经答错或求助后再完成，不算独立完成。移出错题本会保留历史统计。

修改正确答案会撤回完成状态；同一次作答的统计基于作答前快照更新，避免重复累计。

Windows 0.2.x 与 Android 0.2.0 修改题干、选项或答案时会确认重置该题统计并清除该题库的整轮进度；仅调整解析、标签或知识点关联则保留统计与进度。删除当前题目会清除当前练习，删除其他题目会修正队列和总结引用。

## 字号与快捷键

顶部“字号”可分别调整界面字号 **12–20px** 和练习字号 **18–40px**，默认分别为 14px 和 24px。支持滑块、加减与恢复默认，题目、输入框和提示字符同步缩放，重启后保留。

Windows 在“设置 → 答题快捷键”中点击记录框，再按新组合，保存后生效。支持功能键、Enter，以及 Ctrl / Alt 加字母或数字；编辑与系统保留键不可使用。每项可单独停用，冲突时无法保存。

默认按键：F1 按住查看答案、F2 提示、Shift+F3 放弃、F4 跳过、Enter 确认 / 下一题。恢复默认字号会保留自定义快捷键和严格模式开关。

## 数据备份与迁移

### Windows

题库、进度、统计和应用设置位于 EXE 同级的 `data/`，通过“设置 → 打开数据目录”查看。关闭软件后复制整个文件夹即可搬迁，不要只复制 EXE 或用干净发布包替换自己的整个 `data`。

在题库详情选择“导出备份”，JSON 会写入 `data/exports/`，文件名含时间与随机标识，不覆盖已有导出。选择“导入题库 → 选择本地文件”导入 JSON 恢复；同 ID 题库必须确认覆盖。

从旧便携版迁移时，先关闭旧版，复制旧 `data/` 中的 `banks/`、`backups/` 和已有应用设置到新版。开发环境也可使用只复制、不删除源文件、不覆盖已有不同文件的工具：

```powershell
node scripts/migrate-local-data.cjs "旧软件/data" "新软件文件夹"
```

0.1.0 使用过 `%APPDATA%/RecallMate/`；新版不会自动读取或删除该目录。迁移工具同样接受这个旧数据目录作为来源。

发布目录中的数据会在重新构建前备份到 `.cache/release-data-backups/`。日常使用请把软件文件夹放在独立位置，保留自己的备份。

### Android 与跨端迁移

Android 数据保存在应用私有目录。选择题库“导出备份”，在系统保存窗口选择文件位置；导入时也通过系统文件选择器选择 JSON、Markdown 或 TXT。

JSON 包含题库、统计与当前练习进度。Windows 0.2.x 与 Android 0.2.0 可互相导入混合内容包、恢复 V2 完整备份，也可读取旧 V1 填空备份；Android 0.1.2 无法读取新版 V2 数据。字号与快捷键属于本机设置，不随题库 JSON 迁移。Android 卸载或清除应用数据前请先导出；相同签名的新版覆盖安装会保留数据。

### 自动保存与损坏恢复

输入停止 400ms 后保存，判题、提示和切题等操作立即保存。Windows 正常关闭会等待保存完成；Android 进入后台或通过返回键离开练习时主动刷写。保存状态显示在底部，失败时可重试；Android 答题时收起键盘即可看到状态栏。

每个题库保留上一份有效备份。主文件损坏时尝试恢复备份并保留损坏原件；两份均损坏时不覆盖原文件，可从导出的 JSON 恢复。自动备份保存在同一设备中，不能代替外部导出。
