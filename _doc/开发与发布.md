# RecallMate 开发与发布

[返回 README](../README.md) · [使用指南](使用指南.md) · [Android 开发](RecallMate_Android.md)

## 工程与环境

两端共享 `src/domain/` 中的题库解析、答案匹配、提示、统计与会话逻辑。Windows 使用 Electron，Android 使用 Capacitor 和原生文件桥；JSON 题库备份兼容。

| 项目 | 环境 |
| --- | --- |
| 通用 | Node.js 22+；已验证 Node.js 24.11.1、npm 11.6.2 |
| Windows | Windows x64、Git；已验证 Git 2.51.0.windows.2 |
| Android | JDK 21、Android SDK Platform 36、Build-Tools 36.0.0，详见[安卓文档](RecallMate_Android.md) |
| 前端与构建 | React 19、TypeScript 5.9、Vite 7、Electron 45.2.1、electron-builder 26、Capacitor 8.6.0 |

依赖版本锁定于 `package-lock.json`。首次安装与打包需联网下载依赖、Electron 和构建组件；`postinstall` 自动执行 Electron 二进制安装。

## 本地开发

```powershell
npm.cmd ci
npm.cmd run dev
```

也可执行 VS Code 任务“RecallMate: 启动桌面开发版”，或运行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/dev.ps1
```

启动脚本优先使用 PATH 中的 Node.js，然后尝试本机 Trae 运行时，不永久更改环境变量。如果从将 Electron 当作 Node 的宿主中启动，先清除当前进程的 `ELECTRON_RUN_AS_NODE`：

```powershell
Remove-Item Env:ELECTRON_RUN_AS_NODE -ErrorAction SilentlyContinue
```

浏览器预览可运行 `npm.cmd run web`。预览使用浏览器本地存储，与 Windows / Android 的原生数据目录隔离。

## Windows 发布

```powershell
npm.cmd run dist
```

命令执行类型检查、生产构建、Electron 打包和文件夹发布，只生成文件夹便携版。当前发布结构：

```text
release/
  RecallMate-0.1.5-Portable/
    RecallMate.exe
    resources/
    ...                         # Electron 运行资源与许可证
    使用说明.txt
    data/
  RecallMate-0.1.5-Portable.zip
  SHA256SUMS.txt
  android/                      # 由安卓发布脚本独立管理
    RecallMate-Android-0.1.2.apk
    SHA256SUMS.txt
    使用说明.txt
```

Windows 构建中间产物放在 `.cache/build/`。发布脚本先在 `.cache/` 准备完整的干净文件夹与 ZIP，再完整备份旧发布目录的 `data/` 到 `.cache/release-data-backups/`，之后替换旧 Windows 发布项。目录和 ZIP 不含个人题库，`release/` 不应作为日常题库存储目录。

发现未知文件、链接目录或正在从 `release/` 运行的应用时会停止。安卓发布目录独立保留，两个平台的脚本各自维护发布文件。Windows 包只保留已构建的应用代码和资源，排除安卓构建缓存与无需随包分发的 `node_modules`。

Windows EXE 尚未进行发布者代码签名。当前版本不包含自动更新、安装器或自解压 EXE。

## Windows 便携数据

```text
data/
  banks/<bank-id>.json       # 题库、统计与练习会话
  backups/<bank-id>.json.bak
  runtime/                  # Chromium 配置与缓存
  temp/
  logs/
  crashes/
  exports/                  # 手动导出的 JSON
  app-settings.json         # 字号与 Windows 快捷键
  app-settings.json.bak
```

打包版以 EXE 所在文件夹为根目录，不保存机器固定路径。文件夹不可写时提示并退出，不回退到 AppData；打包版忽略外部 `RECALLMATE_DATA_DIR` 覆盖。开发与测试版可接受该变量，开发默认目录为 `.cache/development-data/`。

在 Electron ready 前重定向 `appData`、`userData`、`sessionData`、临时文件、日志和崩溃目录，并为子进程设置 TEMP / TMP / TMPDIR。便携版不自解压，不在系统 TEMP 展开运行时。

这些约束覆盖应用与 Chromium 可配置的写入。Windows、驱动及杀毒软件维护的系统记录不由应用管理，不承诺系统级零痕迹。

每份题库文件为 `{ schemaVersion: 1, bank, session? }`，题库、统计与进度保存在同一文件。写入串行执行，先保留有效旧文件，再写临时文件并替换；主文件损坏时尝试 `.bak`，保留损坏原件为 `.corrupt-时间戳`，两份均损坏时禁止覆盖。

应用设置支持读取旧版纯字号配置并补齐默认快捷键，恢复默认字号不清除快捷键。导入备份只接受受支持 schema、有效 UUID 与完整引用；导入文件不会被改写。数据迁移步骤见[使用指南](使用指南.md#数据备份与迁移)。

## Android 构建与签名

先按[安卓开发说明](RecallMate_Android.md)配置 JDK / SDK，再运行：

```powershell
npm.cmd run android:sync
npm.cmd run android:open
npm.cmd run android:apk
```

使用本机 7890 代理构建：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build-android.ps1 -Proxy http://localhost:7890
```

构建脚本使用本机私有签名密钥，发布前校验 APK 签名。必须保存 `.local/android-signing/`，后续同签名覆盖升级才能保留应用数据。该目录、密钥、环境配置、个人数据及构建缓存均不应提交到 Git。

npm.cmd run build
npm.cmd run test:desktop
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/test-portable-folders.ps1
