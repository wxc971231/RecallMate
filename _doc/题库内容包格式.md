# 题库内容包格式

Windows 与 Android 均支持 `.questionbank.json` 题库内容包，可在一个文件中混合填空、判断、单选、多选，并携带解析和知识点。文件采用 UTF-8、标准 JSON，不包含 Markdown 代码围栏。完整示例见 [四题型示例](../examples/四题型示例.questionbank.json)。

本格式使用 `format: recallmate.question-bank`、`version: 1`，用于新建题库或追加题目，不包含学习记录。完整备份使用 `format: recallmate.backup`、`schemaVersion: 2`，用于恢复统计、进度和当前作答；两者请按用途区分。Markdown / TXT 仍用于 `{{答案}}` 形式的填空题。

## 最小结构

```json
{
  "format": "recallmate.question-bank",
  "version": 1,
  "bank": { "id": "my-bank", "name": "我的题库" },
  "knowledgePoints": [
    { "id": "kp-1", "content": "演示项目支持离线练习。" }
  ],
  "questions": [
    {
      "id": "tf-1",
      "type": "true_false",
      "stem": "演示项目必须联网才能练习。",
      "answer": false,
      "knowledgeRefs": ["kp-1"],
      "explanation": "知识点明确支持离线练习。"
    }
  ]
}
```

## 四种题型

| `type` | 题干与答案 |
| --- | --- |
| `cloze` | `stem` 使用 `{{答案}}`，`|` 分隔可接受答案，不另设 `answer` 或 `options` |
| `true_false` | `answer` 为布尔值 `true` / `false`，不能写成字符串；无 `options` |
| `single_choice` | `options` 是 `[{"id":"A","text":"选项内容"}, ...]`；`answer` 是一个选项 ID |
| `multiple_choice` | `options` 同上；`answer` 是至少两个不重复的选项 ID，如 `["A","C"]`，可以全选 |

选项为 2—26 项，ID 和去除首尾空格的选项文字均不可重复。选项显示字母由数组位置决定，答案始终引用 ID。多选作答按精确集合判定，少选、多选均不通过，输入顺序不限。情景题使用单选或多选，按需添加 `tags: ["情景题"]`。

每题必需 `id`、`type`、`stem`，以及该题型要求的答案和选项。可选字段：

- `label`：原题号，如“情景·3”；`tags`：文本标签数组。
- `explanation`：文本解析，可用 `- A：…` 无序列表逐项填写结论、知识点引用和分析；`knowledgeRefs`：本文件知识点 ID 数组。
- `source`：`{"kind":"manual"}`，kind 可为 `manual`、`exam`、`ai`，可选 name、locator、batchId。只记录来源，不触发联网。
- `reviewStatus`：可为 `ready`、`draft`、`needs_review`，可带 `reviewNote`。后两者在导入前要求用户核对确认，入库后不设审核状态。

`knowledgePoints` 可省略。知识点必需 `id`、`content`，可选 `title`、`source`、`locator`；无需填写法规或来源信息。所有引用必须在同一个包内提供正文，不能只引用聊天记录或另一个未导入文件。

所有外部 ID 为 1—80 位，以英文字母或数字开头，其余可使用字母、数字、点、下划线和连字符。题目 ID 在包内唯一，知识点 ID 在包内唯一，两者不共用命名空间。每包最多 10000 题、10000 知识点，文件不超过 20 MiB。

## 新建、追加和冲突

导入界面先预览题型、题数、知识点和错误，再选择新建或追加。结构错误会阻止导入；未知题目字段会提示并忽略。待复核或未知字段提示需明确勾选确认。

追加时只在选定的题库内比较外部 ID：同 ID 同内容跳过，同 ID 不同内容整批停止。知识点同 ID 异文也会停止，不自动覆盖或重置记录。不同 ID 即使文本相同仍作为不同题目。可合并不同 bank.id 的内容包，bank.id 不作为全局去重键。

当前练习的题目队列不因追加而变化，新题从下一轮开始加入。题库内每道题拥有独立学习记录，错题本按题库隔离，支持题型筛选。

## 内容与备份

“导出题库内容”输出本格式，只含题目、标准答案和知识点，用于分享及追加。它不含统计和进度。

“导出备份”输出 `format: recallmate.backup`、`schemaVersion: 2`，包含当前题库的题目、统计、队列和作答草稿，用于完整恢复。同本地 UUID 的备份需要确认覆盖。

Windows 0.2.0 可读取旧 V1 备份，第一次保存旧数据前把原始文件逐字节保留到 `data/migrations/<题库UUID>.v1.original.json`。归档失败即停止写入。旧题库 ID、题目 ID、统计、作答文字来源及严格模式快照保持不变。回退旧版时，关闭应用后使用迁移原件或升级前整份 data 备份；不要用旧应用读取 V2 文件。

Android 0.2.0 与 Windows 0.2.x 均支持内容包与 V2 备份，可互相导入和恢复。Android 首次迁移保存前将 V1 原文留在应用私有目录的 `files/recallmate/migrations/`，归档失败时不覆盖数据。旧版 Android 0.1.2 不支持新版格式。

## 在外部制题

可让 ChatGPT 按上述格式生成完整 JSON，并提供知识点正文、稳定且不重复的 ID。入库前自行核对题干、标准答案和依据。软件只校验格式和引用，不判断题目事实是否正确，不包含大模型调用、账号或 API 设置。
